# TuringOS Spec (Phase 6.3)

> Generated by `turingos spec` — meta model: `deepseek-v4-pro`

## One-line Goal
A single-page browser tool that helps you compare three project launch plans using weighted criteria scores and instantly highlights the best plan.

## What We're Building (Goal)
A self-contained decision matrix you open as a plain HTML file. You fill in scores for three launch plans across a few criteria, each with a weight, and the tool shows their weighted totals immediately. There's no internet connection, no account, and nothing to install—it works right in your browser. The page makes it obvious which plan comes out on top, so you can decide in minutes.

## Like What (Reference)
It's like a lightweight, single‑purpose decision matrix you might build in a spreadsheet, but without formulas to set up and without the risk of losing your comparison in a pile of notes.

## What the Program Remembers (Memory)
- Three plan names and their score values
- Your criteria names and weights
- The current score table while the page is open
- Computed weighted totals for each plan
- Which plan is currently recommended

## First Run (First Click Walk)
1. Open the HTML file in your browser — you see a table with three columns and several rows.
2. The columns are labeled “Plan 1”, “Plan 2”, “Plan 3”; rows are labeled “Criterion 1”, “Criterion 2”, etc.
3. Edit the plan names, criteria names, and the weight for each criterion directly in the table.
4. For every plan and criterion, type a score from **1 to 5** into the cell.
5. As soon as you type, the weighted total for each plan updates at the bottom of its column.
6. The plan with the highest total is highlighted (for example, with a colored border or badge) so you instantly see the recommendation.
7. You can change any name, weight, or score at any time, and everything recalculates immediately.

## What It Must Not Break On (Robustness)
- A non‑number like “lol” in a score cell — show a warning instead of crashing, and keep the total unchanged.
- Blank scores — the tool treats them as “no score yet” and does not include them in the total, or counts them as 0 without error.
- Two or three plans ending with the exact same total — the page shows that they are tied for the top recommendation.
- Very long plan or criterion names — the layout should stay readable and not break the table.
- Rapid, repeated editing — the weighted totals always remain correct, with no flicker or wrong numbers.

## Deliberately NOT Doing (Out of Scope)
- No user accounts, login, or sign‑up
- No backend server, database, or cloud storage
- No collaboration between users
- No payments or subscription
- No external fonts, CDN links, or remote packages — everything is inside the single HTML file
- No data survives a page reload or browser close (the tool remembers only while the tab is open)
- No import from or export to other file formats (unless a simple paste is later agreed)

## Success Looks Like (Acceptance)
- From opening the file, you can fully enter and compare three plans in **under 5 minutes**.
- Weighted totals update **instantly** with every score change (no save button, no refresh).
- The recommended plan is **clearly distinguishable** from the others (highlighted, bold, or labelled).

## Given/When/Then Examples
**Normal scoring**
- Given I have three plans, criteria, and weights set up
- When I enter scores 1–5 for every cell
- Then the weighted total for each plan appears immediately, and the plan with the highest total is highlighted as the recommended choice.

**Non‑number input**
- Given I'm editing a score cell
- When I type “lol” and move away
- Then the tool shows an inline warning (like “Enter a number 1–5”) and does not change the plan’s total.

**Tied first place**
- Given two plans have exactly the same weighted total after scoring
- When all scores are entered
- Then both plans are marked as tied (e.g., both get the highlighting, or a “tied” label shows they share the top spot).

**Long plan name**

- Then the name displays without breaking the column or overlapping other content.
