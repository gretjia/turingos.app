# TuringOS Spec (Phase 6.3)

> Generated by `turingos spec` — meta model: `deepseek-v4-pro`

## One-line Goal
A self-contained webpage that helps you compare three project launch plans side-by-side and instantly see which one wins.

## What We're Building (Goal)
You open a single HTML file in your browser, no internet needed. You name three plans, define a few criteria with weights, then score each plan on a 1-to-5 scale. As you tap or type, the weighted totals update automatically and the best plan is highlighted. The tool lives entirely in the page; nothing is saved on a server and you never have to log in.

## Like What (Reference)
A lightweight decision-matrix app you might find online, but without any accounts, databases, or cloud features — just a plain, offline-friendly matrix.

## What the Program Remembers (Memory)
- Three plan names
- List of criteria and their weights
- Scores (1–5) for each plan per criterion
- All above only while the page is open (current session)

## First Run (First Click Walk)
1. Open the HTML file in a regular browser.
2. You see three columns labelled Plan 1, Plan 2, Plan 3.
3. Click or tap on each plan’s name to rename it (e.g. “Phased rollout”, “Big bang”).
4. In a separate area, add a criterion (like “Risk”) and set its weight (e.g. 3).
5. For each criterion, click the score cell for each plan and type a number from 1 to 5.
6. The page instantly shows each plan’s total weighted score and marks the highest one.
7. You can keep adjusting names, weights, or scores until you’re comfortable with the recommendation.

## What It Must Not Break On (Robustness)
- Leaving a score cell blank (treats it as zero, doesn’t crash)
- Two or more plans ending up with the same total (shows both as equally recommended)
- Plan names longer than typical (text wraps or truncates, layout stays clean)
- Typing letters or symbols in a score cell (ignores the bad input, keeps the previous valid number)
- No external files loaded; works completely offline

## Deliberately NOT Doing (Out of Scope)
- No login, user accounts, or authentication
- No backend server or database
- No cloud sync or data-sharing between devices
- No multi-user collaboration
- No payment processing
- No external JavaScript packages, fonts, or CDN resources
- No remote network calls of any kind

## Success Looks Like (Acceptance)
- A user can take a real launch-scenario description, type the three plans and criteria, and finish a full comparison within 5 minutes.
- The recommended plan is clearly visible (e.g. highlighted or top-listed) without any confusion.

## Given/When/Then Examples
1. **Given** three plans with names, criteria and weights already added, **when** I set all scores, **then** each plan’s weighted total updates immediately and the highest-scoring plan is visually highlighted.
2. **Given** I leave a score cell blank for one plan on a criterion, **when** I look at the totals, **then** that blank is treated as a score of 0 and does not cause an error.
3. **Given** two plans end up with exactly the same weighted total, **when** the scores are final, **then** both plans are shown as equally recommended (no silent tie-breaking).
4. **Given** I type “xyz” into a score cell that already has a valid number, **when** I move away from the cell, **then** the cell retains the last valid number and ignores the text.
5. **Given** a plan name is very long (over 30 characters), **when** I view the matrix, **then** the name is either truncated or wrapped so the table layout stays readable and no content spills off-screen.

## One-line Brief to the AI Coder
Build a single, self-contained HTML file that lets the user name three plans, add weighted criteria, score each plan 1–5, and instantly see the weighted totals and the recommended plan – with no external resources and graceful handling of empty or invalid input.
